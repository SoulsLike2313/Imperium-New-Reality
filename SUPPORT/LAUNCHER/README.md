# IMPERIUM TERMINAL LAUNCHER V0.1

Script-first launcher. Commands run, print output, and return control to the terminal.

No patch execution is implemented in this patch.

Examples:

```powershell
pwsh SUPPORT/LAUNCHER/imperium.ps1 status
pwsh SUPPORT/LAUNCHER/imperium.ps1 organs
pwsh SUPPORT/LAUNCHER/imperium.ps1 organ astronomicon assembly
pwsh SUPPORT/LAUNCHER/imperium.ps1 patch list
pwsh SUPPORT/LAUNCHER/imperium.ps1 intake dry-run "пишем 60 фпс фикс для ведьмака 3"
```
