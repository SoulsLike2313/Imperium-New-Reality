# Imperium Launcher App Platform V0.1

patch_id: `IMPERIUM-LAUNCHER-APP-PLATFORM-0001`

## What changed

The launcher moves from a terminal menu/window helper into its own application platform under:

```text
SUPPORT/APP/
```

## Run

```powershell
pwsh SUPPORT/APP/imperium_launcher.ps1
```

Double-click entry:

```text
SUPPORT/APP/LAUNCH_IMPERIUM_APP.cmd
```

Self-test:

```powershell
pwsh SUPPORT/APP/imperium_launcher.ps1 -SelfTest
```

## App shape

Tabs:

## Boundary

This is not a packaged exe installer yet. It is a native Windows Forms application platform launched through PowerShell.
