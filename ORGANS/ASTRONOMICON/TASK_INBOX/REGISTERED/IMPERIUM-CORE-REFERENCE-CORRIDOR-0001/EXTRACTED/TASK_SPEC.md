# Task Specification

Task ID: `IMPERIUM-CORE-REFERENCE-CORRIDOR-0001`

## Objective

Build one initial, modular, executable Authoritative Safe Execution Spine from Owner intent to an exact-HEAD external Git worktree and immutable evidence. The result is a reference corridor for Owner review, not a complete MetaOS, complete IDE, autonomous intelligence, or landed Core v1.

## Required vertical slice

`OWNER_INTENT -> TASK_REGISTRATION -> SPECIFICATION -> CONFIDENCE -> STRATEGY -> GREAT_NINE_PREFLIGHT -> THRONE_PREFLIGHT -> OWNER_LAUNCH_APPROVAL -> EXACT_HEAD_WARP -> SAFE_EXECUTION -> VALIDATION -> GREAT_NINE_POSTCHECK -> THRONE_REVIEW -> OWNER_REVIEW -> LAND_PLAN_OR_DISCARD -> IMMUTABLE_EVIDENCE`

## Implementation scope

- Atomic single-task transaction store with stale-base protection.
- One default-deny capability registry consumed by CLI and Thin IDE.
- Typed executor with fixed argv, hashes, timeout, process-tree termination, write-scope and Git-state evidence.
- Exact-HEAD Git worktree lifecycle and owner-gated land-plan generation.
- HEAD-bound evidence envelopes, checkpoints, validator and deterministic organ ledger.
- Owner decision gate and cost/time pause contracts.
- Thin Tauri/Vite surface backed only by live backend contracts.
- Safe diagnostic demo and the mandatory adversarial matrix.
- Compatibility/migration map; no legacy deletion.
