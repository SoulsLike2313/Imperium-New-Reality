## Law

The body of IMPERIUM must physically obey the doctrine it preaches. A doctrine that
lives only in prose, while the file tree contradicts it, is itself a fake-green.

## Articles

1. PHYSICAL CLEANLINESS IS PART OF TRUTH.
   Committed build artifacts, BOM-broken receipts, unadmitted zip payload and CRLF dirt
   are doctrine violations, not cosmetic issues.

2. RECEIPTS MUST BE MACHINE-READABLE.
   A receipt that a strict JSON parser cannot read (because of a BOM) is not a receipt.
   All canonical receipts are ENGLISH UTF-8 NO-BOM, LF endings.

3. CLAIMS REQUIRE REPLAYABLE EVIDENCE.
   "Clean" requires a git-truth receipt or an explicit AUTHORITY_GAP. "Hygienic"
   requires a hygiene-gate report. No hand-claim replaces a script result.

4. METRICS MUST NOT BE BLIND.
   A cleanliness metric that inspects only root entries, while 79 percent of the repo
   is artifacts hidden inside an Organ, produces a comfortable lie. Metrics scan recursively.

5. NEGATIVE FIXTURES ARE SACRED.
   Intentionally malformed fixtures and detector test patterns must remain broken.
   Cleaning them would destroy the tests that protect the system.

## Enforcement

This law is enforced by MECHANICUS hygiene gate (BLOCK on artifacts/zip/malformed/secret)
and by the ADMINISTRATUM git-truth receipt. INQUISITION downgrades any PASS that lacks them.
