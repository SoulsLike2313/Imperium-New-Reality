# PACK TAXONOMY AND SERVITOR TASK LAW V0.1

patch_id: `DOCTRINARIUM-PACK-TAXONOMY-AND-SERVITOR-TASK-LAW-0001`

## Core formulae

```text
Owner + Logos Prime = Patch Pack
Owner + Logos Prime + Servitor = Task Pack
```

## Patch Pack

Patch Pack is the manual WARP package created by Owner + Logos Prime. It lives in `WARP/PATCHES/<PATCH_ID>/`. It may change Reality only through explicit runner, validator, receipt and Owner commit flow.

## Task Pack

Task Pack is not every task. Task Pack is a valid Servitor work order. It is dispatchable only after authority, context, output contract, validation plan, stop conditions, forbidden actions and custody path are defined and validated.

## Intake Draft

Astronomicon dry-run creates an Intake Draft, not a valid Task Pack. Current home: `WARP/TASKS/<TASK_ID>/00_INTAKE/`.

## Servitor Output

Servitor output is untrusted. It is not a Patch Pack and cannot mutate Reality. Any Reality mutation must be converted by Owner + Logos Prime into a normal Patch Pack.

## Gate law

```text
registration != validation
validation != execution
execution != trust
trust != Throne verdict
receipt existence != work done
```
