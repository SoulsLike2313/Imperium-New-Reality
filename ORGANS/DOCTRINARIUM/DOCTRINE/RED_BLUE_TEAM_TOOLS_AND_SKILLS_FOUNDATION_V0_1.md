# RED + BLUE TEAM TOOLS AND SKILLS FOUNDATION V0.1

patch_id: `RED-BLUE-TEAM-TOOLS-AND-SKILLS-FOUNDATION-0001`

## Purpose

Every organ needs two internal defensive/offensive skill lanes:

```text
Red Team — searches for vulnerabilities in the organ's own domain.
Blue Team — protects, hardens, explains and recommends attention zones in the organ's own domain.
```

This patch defines the lanes and provides baseline machine validation.

## Important boundary

```text
red_blue_defined != red_blue_proven
red_blue_tool_exists != organ assembled
red_blue_scan != Custodes trust
red_blue_scan != Throne verdict
```

## Organ law

Each organ must have:

```text
red_skills
blue_skills
profile_scope
allowed_outputs
forbidden_claims
proof_state
required_future_validators
```

The skill lane may say:

```text
attention zone: fake-green risk
evidence: missing trust validator
risk score: 80
```

It must not say:

```text
execute this command
mutate this file
trust is proven
Throne confirmed
```
