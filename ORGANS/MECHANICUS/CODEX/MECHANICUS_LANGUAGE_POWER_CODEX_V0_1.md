## Prime rule

Imperium must not become a Python-only machine.

Python is excellent glue: scripts, validators, receipts, orchestration, quick scans, reports and artifact generation. But Python is not the only judge of reality.

Mechanicus must store language powers, know when to recommend each language, know what proof command verifies the toolchain, and know how Python may bind or orchestrate the result.

## Language doctrine

- Python binds and orchestrates.
- Rust judges and guards where deterministic compiled validators matter.
- Go ships simple fast CLIs and services.
- TypeScript drives app/web cockpit surfaces.
- PowerShell controls Windows operator workflows.
- C++ descends only when deep native optimization is justified.

## Proof law

A language is not available because the model says so.

A language is available when Mechanicus can produce toolchain evidence:

```text
version command PASS
compile/check command PASS
minimal artifact command PASS where applicable
```

## Recommendation law

Mechanicus recommends a language by task shape, not taste.

Example:

- fast repo scan / glue / receipts → Python
- strict validator / safety gate / binary tool → Rust
- simple distributable CLI / worker → Go
- browser/app shell → TypeScript
- Windows hotkey/operator scripts → PowerShell
- native hot path / image/audio/graph core → C++ only after profiling

## Not claimed

This codex does not claim all toolchains are installed, all compilers pass, or all languages are currently integrated. It defines the policy and evidence shape. Actual availability must be proven by later Mechanicus machine-state scans.
