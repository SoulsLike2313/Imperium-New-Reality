# THRONE BOUNDARIES V0.1

## Allowed now

- create and validate the Throne foundation;
- measure gaps;
- write receipts and reports;
- define target-v1 forms;
- define future validation zones;
- expose data for dashboards/TUI/Eyes.

## Not allowed now

- hard BLOCK of working cycles;
- direct visual refit;
- pretending current reality is v1;
- overriding Owner decisions;
- land without receipt;
- fake-green validation.

## Visual boundary

Eyes/Graph Viewer visual refit is frozen.

Throne may later emit data feeds for the stable accepted viewer, but may not redesign visuals in this phase.
