## Purpose

Create the first physical Crown Organ: `ORGANS/THRONE/`.

This patch does not attempt to complete the Throne v1. It creates the minimum living Throne base that can validate its own form and later host tons of validators, target-v1 matrices, organ relationship validators, dashboards, TUI, Eyes data exports, receipts, and enforcement policy.

## Why this exists

The population census proved that the Imperium now has a measurable population baseline.

The next step is to create the organ that will read that reality, compare it against ideal target forms, and report the gap to v1.

The Throne must not validate current chaos as if it were truth. The Throne validates:

```text
TARGET V1 FORM vs CURRENT REALITY
```

The first Throne therefore needs:

- identity;
- organ card;
- manifest;
- self-knowledge;
- target-v1 matrix;
- validation mode matrix;
- organ relationship matrix;
- schemas;
- first self-form validator;
- receipt and report output.

## PASS meaning

`PASS` means:

- `ORGANS/THRONE/` exists;
- required organ slots exist;
- Throne declares itself as `CROWN_ORGAN`;
- Throne mode is `MEASURE_ONLY`;
- Great Nine list is present and exact;
- Owner override policy is `OWNER_ONLY`;
- visual refit remains frozen;
- target validation model is `TARGET_V1_VS_CURRENT_REALITY`;
- target-v1 matrix exists and is parseable;
- self-form receipt and report are generated by script.

`PASS` does not mean the Throne is complete.

It means the first heartbeat of the Throne is alive and measurable.
