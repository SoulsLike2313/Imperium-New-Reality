# IMPERIUM_PHASE6_COMMITTED_HEAD_BASELINE_FIX_0005

Этот пакет исправляет только закон baseline Phase 6.

Почему нужен новый live-клик:
- первый baseline был снят на HEAD `8f34f78f...` с незакоммиченным кодом;
- реализация затем стала коммитом `8c3a3630478c53e19fead8e18ec165adc5062cbe`;
- старый verifier правильно блокирует перенос доказательства на другой HEAD;
- старый receipt не считается финальным после этого BLOCK.

Правильная процедура:
1. RUN — применить поддержку committed-head baseline и тесты.
2. Закоммитить два файла реализации.
3. CAPTURE — архивировать попытку 01 и снять новый baseline на чистом HEAD.
4. В IDE нажать Run Diagnostic ровно один раз, затем Refresh.
5. VERIFY — доказать ровно один новый evidence относительно нового baseline.
6. Только затем создать evidence-коммит.

Первый evidence не удаляется и остаётся историей.
