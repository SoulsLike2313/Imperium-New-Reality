# MECHANICUS

Mechanicus is the organ of machine reality.

It proves what the machine can actually build, compile, run, validate, split, and maintain.

## Core mandate

```text
Idea -> technical form -> language -> toolchain -> build -> runtime -> receipt -> maintainability.
```

## Primary duties

- language surface census;
- toolchain proof;
- language/task selection;
- build and runtime proof;
- no-monolith architecture discipline;
- code purity gates;
- UI workshop tools;
- backend modularity rules;
- polymorphic implementation forms.

## Core law

```text
Form may change.
Function must not be lost.
```

A UI, game shell, CLI, launcher, or webview is only an operator surface. Truth lives in receipts, registries, validators, contracts, tools, and evidence.
