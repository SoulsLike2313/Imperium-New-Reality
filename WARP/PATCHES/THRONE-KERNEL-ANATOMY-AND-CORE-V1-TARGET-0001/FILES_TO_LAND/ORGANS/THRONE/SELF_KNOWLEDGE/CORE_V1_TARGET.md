# CORE V1 TARGET

Imperium Core v1 is a verified hybrid meta-kernel for task creation, execution routing, validation, evidence capture, and human-readable governance.

It is not an IDE yet. It is not a general autonomous agent yet. It is not a monolith.

## Core v1 oath

1. Verifiability of result
2. Quality of result
3. Core safety
4. Learnability

## Core v1 must eventually prove

Owner intent -> registered task pack -> Astronomicon intake -> Administratum registration/context -> servitor execution boundary -> WARP work -> organ validation -> Inquisition dirt/fake-green check -> Custodes trust check -> Throne verdict -> external product / land / abort -> receipts, lessons, metrics -> human-readable TUI/dashboard state.

## Benchmark policy

Benchmark is postponed until the Great Nine and workflow validators are meaningful enough.

## No-core-mutation

External products do not become core. Allowed return into core: receipts, reports, lessons, metrics, and reusable templates/tools only through WARP, validation, Throne verdict, and land.

## Human readability

Core v1 must translate machine receipts/status/verdicts into a human-readable operational picture.
