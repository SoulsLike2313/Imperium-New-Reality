# THRONE ORGAN TRUTH STAGE NOTES V0.1

patch_id: `DOCTRINARIUM-ORGAN-DUTY-CONTRACT-SCHEMA-0001`

## Law

```text
profile_baseline != duty_defined != rule_validated != action_proven != trust_proven != throne_confirmed
```

## Meaning

This patch defines organ duties.

It must not claim that organs are operationally proven.

It gives Throne a stricter language for later validators:

- a passported organ is not a working organ;
- a duty-defined organ is not a working organ;
- a self-validator is not trust proof;
- a receipt must be cross-checked before Crown truth.
