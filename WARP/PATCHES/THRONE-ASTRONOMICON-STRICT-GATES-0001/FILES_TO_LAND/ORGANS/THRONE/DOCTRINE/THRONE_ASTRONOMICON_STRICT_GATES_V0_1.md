# THRONE ASTRONOMICON STRICT GATES V0.1

patch_id: `THRONE-ASTRONOMICON-STRICT-GATES-0001`

## Crown role

Throne is severe, impartial, and non-conversational.

It does not comfort an organ, and it does not negotiate with an organ.

It asks:

```text
Is the evidence real?
Did Custodes prosecute it?
Are there any indictments?
Are the claimed capabilities actually present?
Are the validators working?
Are the boundaries honest?
Is anything claiming more than it is allowed to claim?
```

If one hard gate fails, Crown PASS is blocked.

## Difference from Custodes

```text
Custodes = prosecutor.
Throne = Crown sentence / final gate.
```

Custodes proves that Astronomicon is not lying.

Throne decides whether that proof is enough to raise Astronomicon's stage status.

## Boundary

This patch may confirm Astronomicon's strict local Crown gate.

It must not claim:

```text
global organ assembled
Core v1 ready
Great Nine complete
visual work resumed
Throne self-validation
```
