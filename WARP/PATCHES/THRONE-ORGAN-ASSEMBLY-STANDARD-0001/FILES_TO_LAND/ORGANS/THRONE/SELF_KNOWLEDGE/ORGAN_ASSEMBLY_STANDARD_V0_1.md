# ORGAN ASSEMBLY STANDARD V0.1

patch_id: `THRONE-ORGAN-ASSEMBLY-STANDARD-0001`

## Owner intent

Raising an organ means introducing it into real Core service.

An organ is not assembled because it has a README, passport, manifest, or duty contract.

An organ is assembled only when it has:

1. personal place in terminal launcher / TUI command surface;
2. personal organ tools, scripts, functions, documents, and workflows;
3. personal validators for work flowing through the organ and validators for the organ's own honesty;
4. Custodes validators that attack the organ's work, authority, validator honesty, and trust chain;
5. Throne validators that decide whether the organ's proof counts as Reality;
6. red-team and blue-team layers for organ-specific vulnerabilities and defenses.

## Launcher law

TUI must be launcher-shaped:

```text
imperium organ <ORGAN> status
imperium organ <ORGAN> functions
imperium organ <ORGAN> receipts
imperium organ <ORGAN> validate self
imperium organ <ORGAN> validate custodes
imperium organ <ORGAN> validate throne
imperium organ <ORGAN> red
imperium organ <ORGAN> blue
```

The command runs, reports, writes receipts if needed, and returns control to the terminal.

## Stage law

```text
profile_baseline != duty_defined != assembly_target_defined != rule_validated != action_proven != trust_proven != throne_confirmed != organ_assembled
```

## No fake green

This patch defines the assembly standard.

It does not assemble the organs.
